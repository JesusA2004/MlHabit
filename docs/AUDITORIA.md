# Auditoría inicial del repositorio (2026-10-27)

Base recibida: CMS editorial "MR. INSIGHT" (Laravel 13.35, PHP 8.4, Inertia 3, Vue 3, Tailwind 4, shadcn-vue, Wayfinder, Fortify, Pest 5, Larastan, Pint, Intervention Image 3, vite-plus 0.3). Un solo commit (`inicio de proyecto ml habit`).

## Diagnóstico

- Suite original: 136 pruebas, 42 fallaban solo por ausencia del manifiesto de Vite (sin build); configuradas contra SQLite en memoria.
- Base de datos local: WAMP con MySQL 8.4 (3306) y **MariaDB 11.4.9 (3307)**. MariaDB tenía `default_storage_engine=MyISAM`: se fuerza `InnoDB` en `config/database.php` (indispensable para FK y bloqueos de fila).
- Herramientas: Laravel Boost instalado (comandos `boost:*`) sin `.mcp.json` configurado; FFmpeg disponible; extensiones `bcmath`, `gd`, `intl`, `pdo_mysql`, `sodium`.

## Deuda técnica encontrada

- `phpunit.xml` dependía de SQLite → ahora MariaDB.
- Autorización basada en `isAdmin()`/`canManagePosts()` dispersos → reemplazada por permisos (`App\Enums\Permission`) + Gates + Policies.
- Textos y rutas de `.env.example`, comandos (`mrinsight:*`), colecciones de medios y SFTP con marca anterior → renombrados.
- `.claude/` en `.gitignore`: los skills del proyecto anterior no se versionaban.
